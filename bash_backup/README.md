## archive_saver

Bash script ```filearchive_saver``` pulls archives from another server
and pushes them to an external storage device. Secure FTP and
copying is used. The script requires memory to temporarily 
store all the archives from a run. See also the comment in the 
script and in ```demo_archive_saver.conf```.

## Bash versions

Bash scripts should run with

* GNU bash, version 5.3.20(0)-release (FreeBSD 14.4)
* GNU bash, version 5.2.21(1)-release (Ubuntu 24.04 LTS)

or higher.
